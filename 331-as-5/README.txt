Assignment 5: Frequency
===================

A collection of Python scripts that:
1. maps letters in cipheralphabet to plainalphabet based on frequency,
 decrypts substitution ciphertexts based on this mapping

2. find the key, decipher accuracy of ciphertext deciphered using a certain mapping

3. get frequency of each char in ciphertext
PREREQUISITES
-------------
Python 3.8.10 (Standard Library only)

USAGE
-----
Run any problem script from the root directory, for example:
    python3 a5p1.py
