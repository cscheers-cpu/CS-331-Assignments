Assignment 3: Affine
===================

A collection of Python scripts that:
1. Find number of possible affine a,b key pairings given modulus m
2. Generate list of pseudo-random numbers according to algorithm Ri+2 = (aRi+1 + bRi + c) (mod m) i ≥ 0
3. Find a, b, c values given a sequence of 5 numbers generated using algorithm Ri+2 = (aRi+1 + bRi + c) (mod m) i ≥ 0
PREREQUISITES
-------------
Python 3.8.10 (Standard Library only)

USAGE
-----
Run any problem script from the root directory, for example:
    python3 a3p2.py
