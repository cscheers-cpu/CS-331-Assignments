Assignment 4: Cryptanalysis
===================

A collection of Python scripts that:
1. crack columnar, caesar, and affine cyphers stored in ciphers.txt
2. decrypt and encrypt substitution ciphers using nomenclators
3. find missing letters from a ciphertext that has been partially solved
PREREQUISITES
-------------
Python 3.8.10 (Standard Library only)

USAGE
-----
Run any problem script from the root directory, for example:
    python3 a3p4.py
